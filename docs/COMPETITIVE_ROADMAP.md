# AuroraPad Competitive Roadmap

AuroraPad’s strongest paid differentiation opportunities are not basic text editing. The most credible commercial paths are remote workflows, team controls, AI-assisted operations, and enterprise trust.

## Paid Feature Lanes

### Pro Remote

- Remote sync and compare
- Checksum verification
- Conflict history and recovery
- Saved remote tasks and runbooks
- Rich profile migration bundles

### Pro Productivity

- Session templates
- Workspace automation
- File compare and merge
- Search presets and saved filters
- Advanced snippets and macros

### Teams

- Shared remote profiles without shared secrets
- Policy-managed command catalogs
- Audit logs
- Centralized billing
- Role-based administration

### Enterprise

- SSO and SAML
- SCIM provisioning
- Signed configuration bundles
- Organization policy controls
- Deployment provenance and support SLAs

## Competitor Patterns Covered

- AI and agent value: Cursor, Windsurf, GitHub Copilot
- Premium editor ownership and pro workflows: Sublime Text, BBEdit, UltraEdit, Nova
- Remote-first premium value: Termius, ForkLift, Transmit
